## Calculadora de IMC

Projeto desenvolvido com HTML, CSS e JavaScript.

A aplicação permite calcular o Índice de Massa Corporal (IMC) do usuário com base no peso e na altura informados. Dando a informação se o usuário esta no peso normal, acima do peso ou abaixo do peso. E se por a Caso nada seja informado pelo usuário, uma mensagem aparece na tela Por favor informe seu peso e sua altura.
